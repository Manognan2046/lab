# Web Programming Lab Website

## Folder contents
- index.html — main page with all 50 clickable questions
- questions/ — one HTML page for each question
- assets/style.css — website styling
- lab-record.pdf — the original supplied PDF

## How to put this into your GitHub Desktop `wp` branch
1. Open GitHub Desktop.
2. Select repository `lab`.
3. Make sure the current branch says `wp`.
4. Click Repository -> Show in Explorer.
5. Copy EVERYTHING from this folder into the local `lab` repository folder.
6. Return to GitHub Desktop. You should see the new files under Changes.
7. In Summary, type: `Add question-wise web programming lab`
8. Click `Commit to wp`.
9. Click `Push origin`.

## How to test it
Double-click `index.html` to open the website locally.
Click a question. Each question opens its own page.

## If you later enable GitHub Pages
Publish the `wp` branch (or the folder you choose in GitHub Pages settings). The site will then be accessible from a browser.
