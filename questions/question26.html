QUESTION 26

Develop and demonstrate JavaScript with POP-UP boxes and functions for the
$ cat solution
following problem. 
Input: A number n obtained using prompt. 

 
Output: A multiplication table of numbers from 1 to 10 of n using alert 
 
<!DOCTYPE html> 
<html> 
<head> 
  <title>Multiplication Table using JS Pop-Ups</title> 
  <script> 
    function showMultiplicationTable() { 
      var n = prompt("Enter a number:"); 
      n = Number(n); // convert to number 
 
      if (isNaN(n)) { 
        alert("Invalid input. Please enter a valid number."); 
        return; 
      } 
 
      var table = "Multiplication Table of " + n + ":\n"; 
      for (var i = 1; i <= 10; i++) { 
        table += n + " x " + i + " = " + (n * i) + "\n"; 
      } 
 
      alert(table); 
    } 
  </script> 
</head> 
 
<body onload="showMultiplicationTable()"> 
  <h2>Multiplication Table using JavaScript Pop-Up Boxes</h2> 

 
  <p>Check the alert box for output.</p> 
</body> 
</html>
