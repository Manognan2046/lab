QUESTION 7

Design the following static web pages required for Library Management System web site
$ cat solution
web site and link these pages to home page using hyperlinks in HTML. Home, About 
Us, List of Books, l.index.html (Home Page): 
 
Index.html 
<!DOCTYPE html> 
<html> 
<head> 
  <title>Library Management System</title> 
</head> 
<body style="font-family: Arial; background-color: #f2f2f2;"> 
  <h1>Welcome to the Library Management System</h1> 
  <nav> 
    <a href="index.html">Home</a> | 
    <a href="about.html">About Us</a> | 
    <a href="books.html">List of Books</a> 
  </nav> 
  <hr> 
  <p>This is the home page of the Library Management System. Use the links above to 
navigate through the site.</p> 
</body> 
</html>
