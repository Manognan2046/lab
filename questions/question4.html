Question 4

Write a HTML program to demonstrate MOUSE EVENTS

Code / Solution from the Record

<!DOCTYPE html> 
<html> 

 
<head> 
    <title>Mouse Events Example</title> 
    <script> 
        function mouseOver() { 
            document.getElementById("text").style.color = "blue"; 
} 
        function mouseOut() { 
            document.getElementById("text").style.color = "black"; 
        } 
        function mouseClick() { 
            alert("Paragraph clicked!"); 
        } 
    </script> 
</head> 
<body> 
    <h2>Mouse Events Demo</h2> 
    <p id="text" onmouseover="mouseOver()" onmouseout="mouseOut()" 
onclick="mouseClick()"> 
        Hover over this text and click it! 
    </p> 
</body> 
</html>
