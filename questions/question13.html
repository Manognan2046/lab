QUESTION 13

Write a program that changes the background color of a webpage dynamically using inline
$ cat solution
using inline styles, and also includes a button to toggle between two external 
stylesheets. 
<!DOCTYPE html> 
<html> 
<head> 
  <title>Dynamic Styles and Stylesheet Toggle</title> 
  <link id="styleSheet" rel="stylesheet" href="style1.css"> 
  <script> 
    function changeBgColor(color) { 
      document.body.style.backgroundColor = color; 
    } 
    function toggleStyleSheet() { 
      var sheet = document.getElementById("styleSheet"); 
      if (sheet.getAttribute("href") === "style1.css") { 
        sheet.setAttribute("href", "style2.css"); 
      } else { 
        sheet.setAttribute("href", "style1.css"); 

 
      } 
    } 
  </script> 
</head> 
<body> 
  <h2>Dynamic Background Color and Stylesheet Toggle</h2> 
   <button onclick="changeBgColor('lightblue')">Light Blue</button> 
  <button onclick="changeBgColor('lightgreen')">Light Green</button> 
  <button onclick="changeBgColor('lightpink')">Light Pink</button> 
 <br><br> 
 <button onclick="toggleStyleSheet()">Toggle Stylesheet</button> 
  <p>This paragraph will reflect styles from the external stylesheet.</p> 
</body> 
</html> 
style1.css 
body { 
  font-family: Arial, sans-serif; 
  color: darkblue; 
} 
p { 
  font-size: 18px; 
} 
style2.css  
body { 
  font-family: "Courier New", monospace; 
  color: darkgreen; 

 
} 
p { 
  font-size: 20px; 
  font-weight: bold; 
}
