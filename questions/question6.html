Question 6

Design the following web pages of college web site and link these pages to home page

Code / Solution from the Record

page using frames in HTML-Home, About Us, Courses Offered, 
Admissions.i.index.html (Home Page with Frameset) 

index.html  
<!DOCTYPE html> 
<html> 
<head> 
  <title>College Website</title> 
</head> 
<frameset rows="20%,80%"> 
  <!-- Top Frame for Heading --> 
  <frame src="home.html" name="topFrame" scrolling="no" noresize> 
 
  <!-- Bottom frame with 2 columns --> 
  <frameset cols="20%,80%"> 
    <!-- Left Frame for Menu --> 
    <frame src="menu.html" name="menuFrame"> 
     
    <!-- Right Frame to display content --> 
    <frame src="about.html" name="contentFrame"> 
  </frameset> 
</frameset> 

 
</html> 
 
menu.html  
<!DOCTYPE html> 
<html> 
<head> 
  <title>Menu</title> 
</head> 
<body bgcolor="#f0f0f0"> 
  <h3>Navigation</h3> 
  <ul> 
    <li><a href="home.html" target="topFrame">Home</a></li> 
    <li><a href="about.html" target="contentFrame">About Us</a></li> 
    <li><a href="courses.html" target="contentFrame">Courses Offered</a></li> 
    <li><a href="admissions.html" target="contentFrame">Admissions</a></li> 
  </ul> 
</body> 
</html>
