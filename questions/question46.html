QUESTION 46

Develop a simple JSP application
$ cat solution
index.jsp – Input Form 
 

 
<!DOCTYPE html> 
<html> 
<head> 
    <title>Simple JSP App</title> 
</head> 
<body style="font-family: Arial; text-align: center; padding-top: 100px;"> 
    <h2>Welcome to My JSP App</h2> 
    <form action="welcome.jsp" method="post"> 
        Enter your name: <input type="text" name="username" required> 
        <br><br> 
        <input type="submit" value="Submit"> 
    </form> 
</body> 
</html> 
welcome.jsp – Display Output 
<%@ page contentType="text/html;charset=UTF-8" language="java" %> 
<% 
    String name = request.getParameter("username"); 
%> 
<!DOCTYPE html> 
<html> 
<head> 
    <title>Welcome</title> 
</head> 
<body style="font-family: Arial; text-align: center; padding-top: 100px;"> 
    <h2>Hello, <%= name %>!</h2> 
    <p>Welcome to this simple JSP application.</p> 
</body> 
</html>
