Demonstrate TRANSITIONS and TRANSFORMATION

Code / Solution from the Record

<!DOCTYPE html> 
<html> 
<head> 
  <title>Transitions and Transformations Demo</title> 
  <style> 
    .box { 
      width: 150px; 
      height: 150px; 
      background-color: teal; 
      margin: 50px; 
      transition: all 0.5s ease; /* transition applied */ 
    } 
 
    .box:hover { 
      background-color: orange; /* transition color change */ 
      transform: scale(1.2) rotate(20deg) translateX(30px); /* transformation */ 
    } 
 
    .text { 
      font-size: 20px; 
      transition: color 1s, transform 1s; 
    } 
 
    .text:hover { 
      color: purple; 

 
      transform: skewX(20deg); 
    } 
  </style> 
</head> 
<body> 
  <h2 align="center">CSS Transitions and Transformations Demo</h2> 
 
  <div class="box"></div> 
 
  <p class="text">Hover over this text to see skew transformation and color transition.</p>
