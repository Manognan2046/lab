Program on steps to install IIS web server.

Code / Solution from the Record

<!-- 
STEP 1: INSTALL IIS ON WINDOWS 
=============================== 
1. Open Control Panel 
2. Go to "Programs" > "Turn Windows features on or off" 
3. In the list, check "Internet Information Services" 
4. Click OK and wait for installation to complete 
 
STEP 2: PLACE THIS FILE IN THE IIS ROOT FOLDER 
============================================== 
1. Save this file as index.html 
2. Move it to this folder: C:\inetpub\wwwroot\ 
   (This is the default root directory of IIS) 
3. You may need admin permission to paste the file 
 
STEP 3: TEST IN YOUR BROWSER 
============================ 
1. Open your web browser 
2. Go to: http://localhost 
3. You should see the webpage below 
 
NOTE: IIS must be running. You can restart it using the command: 
      iisreset (in Command Prompt as Administrator) 
-->
