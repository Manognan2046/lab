Question 10

Develop and demonstrate the usage of inline, internal and external style sheet using CSS.

Code / Solution from the Record

using CSS 
  
<!DOCTYPE html> 
<html lang="en"> 
<head> 
    <meta charset="UTF-8"> 
    <title>CSS Styling Demonstration</title> 
    <style> 
        body { 
            font-family: Arial, sans-serif; 
            background-color: #f5f5f5; 
            margin: 0; 
            padding: 0; 
        } 
 
        .internal-style { 
            color: blue; 
            text-align: center; 
        } 

 
 
        .external-style { 
            color: purple; 
            font-size: 18px; 
            text-align: justify; 
        } 
 
        footer { 
            background-color: #333; 
            color: white; 
            text-align: center; 
            padding: 10px 0; 
        } 
    </style> 
</head> 
<body> 
    <header> 
        <h1 style="color: red;">Inline CSS Example</h1> 
    </header> 
    <main> 
        <p class="internal-style">This paragraph is styled using Internal CSS.</p> 
        <p class="external-style">This paragraph is styled using External CSS.</p> 
    </main> 
    <footer> 
        <p style="color: green;">This footer is styled using Inline CSS.</p> 
    </footer> 
</body> 
</html>
