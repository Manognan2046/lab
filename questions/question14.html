Question 14

Write a program to create blurred pictures and text with different direction and strength

Code / Solution from the Record

strength using Motion Blur filter in CSS. 
<!DOCTYPE html> 
<html> 
<head> 
  <title>Motion Blur Simulation in CSS</title> 
  <style> 
    .container { 
      display: flex; 
      flex-wrap: wrap; 
      gap: 20px; 
      justify-content: center; 
      padding: 20px; 
    } 
 

 
    .blur-horizontal { 
      filter: blur(0.5px); 
      transform: translateX(3px); 
    } 
 
    .blur-vertical { 
      filter: blur(1px); 
      transform: translateY(5px); 
    } 
 
    .blur-strong { 
      filter: blur(4px); 
      transform: translateX(10px); 
    } 
 
    .text-blur { 
      color: black; 
      font-size: 24px; 
      text-shadow: 5px 0 3px rgba(0,0,0,0.3); /* horizontal motion blur simulation */ 
    } 
 
    .text-blur-vertical { 
      color: darkblue; 
      font-size: 24px; 
      text-shadow: 0 5px 3px rgba(0,0,0,0.3); /* vertical motion blur simulation */ 
    } 

 
 
    img { 
      width: 200px; 
      height: auto; 
    } 
  </style> 
</head> 
 
<body> 
  <h2 align="center">CSS Motion Blur Simulation</h2> 
   
  <div class="container"> 
    <div> 
      <p>Original Image</p> 
      <img src="image.jpg" alt="Original"> 
    </div> 
    <div> 
      <p>Horizontal Motion Blur</p> 
      <img src="image.jpg" class="blur-horizontal" alt="Horizontal Blur"> 
    </div> 
    <div> 
      <p>Vertical Motion Blur</p> 
      <img src="image.jpg" class="blur-vertical" alt="Vertical Blur"> 
    </div> 
    <div> 
      <p>Strong Motion Blur</p> 

 
      <img src="image.jpg" class="blur-strong" alt="Strong Blur"> 
    </div> 
  </div> 
 
  <div class="container"> 
    <div> 
      <p class="text-blur">This is Horizontal Blurred Text</p> 
    </div> 
    <div> 
      <p class="text-blur-vertical">This is Vertical Blurred Text</p> 
    </div> 
  </div> 
 
</body> 
</html>
