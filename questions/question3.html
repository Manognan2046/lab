QUESTION 3

Write a HTML program to demonstrate ONCLICK and ONLOAD
$ cat solution
<!DOCTYPE html> 
<html> 
<head> 
    <title>ONCLICK and ONLOAD Example</title> 
    <script> 
        
        function pageLoaded() { 
            alert("Welcome! This alert is shown using ONLOAD."); 

 
        } 
 
       
        function showMessage() { 
            alert("Button was clicked! This is ONCLICK."); 
        } 
    </script> 
</head> 
<body onload="pageLoaded()"> 
 
    <h2>ONCLICK and ONLOAD Example</h2> 
 
    <p>Click the button below to see the ONCLICK event in action:</p> 
    <button onclick="showMessage()">Click Me</button> 
</body> 
</html>
