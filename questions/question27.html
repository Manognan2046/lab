QUESTION 27

Develop and demonstrate a HTML file that includes Java script for the following
$ cat solution
problems: 
Input: A number n obtained using prompt 
Output: A table of numbers from 1 to n and their squares using alert 
 
<!DOCTYPE html> 
<html> 
<head> 
  <title>Numbers and Squares using JS Pop-Ups</title> 
  <script> 
    function showSquaresTable() { 
      var n = prompt("Enter a number:"); 
      n = Number(n); // Convert input to number 
 

 
      if (isNaN(n) || n < 1) { 
        alert("Invalid input. Please enter a positive number."); 
        return; 
      } 
 
      var result = "Number\tSquare\n"; 
      for (var i = 1; i <= n; i++) { 
        result += i + "\t" + (i * i) + "\n"; 
      } 
 
      alert(result); 
    } 
  </script> 
</head> 
 
<body onload="showSquaresTable()"> 
  <h2>Numbers and their Squares using JavaScript Pop-Up Boxes</h2> 
  <p>Check the alert box for output when the page loads.</p> 
</body> 
</html>
